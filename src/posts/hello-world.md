# 你好，世界

欢迎来到我的博客。这是第一篇文章，用来测试整个站点的搭建是否正常。

> 写作是最好的思考方式。—— 这句话经常出现在很多人的博客里，我也深以为然。

## 这个站点

本站使用以下技术栈搭建：

| 用途 | 技术 |
| ---- | ---- |
| 框架 | Vue 3 |
| 构建工具 | Vite |
| 路由 | Vue Router |
| 样式 | Tailwind CSS |
| 内容 | Markdown |

## 我会写些什么

- **技术笔记**：Vue、前端工程化相关的心得
- **工具教程**：好用工具的用法
- **生活随想**：偶尔的碎碎念

启动本地开发服务器：

```bash
npm install
npm run dev
```

就这样，开始吧。

# Markdown 写作语法速查

Markdown 是一种轻量级标记语言，用纯文本即可写出结构清晰的文档。这篇速查覆盖了博客写作的常用语法。

## 标题

```md
# 一级标题
## 二级标题
### 三级标题
```

## 强调与列表

```md
**加粗** 与 *斜体* 与 ~~删除线~~

- 无序列表项
- 第二项
  - 嵌套项

1. 有序列表
2. 第二项
```

效果：

**加粗** 与 *斜体* 与 ~~删除线~~

- 无序列表项
- 第二项
  - 嵌套项

1. 有序列表
2. 第二项

## 引用

```md
> 这是引用块。
```

> 这是引用块。

## 代码

行内代码用反引号：`npm run dev`。

代码块用三个反引号并标注语言：

```js
function greet(name) {
  return `你好，${name}！`
}
```

## 链接与图片

```md
[Vue 官方文档](https://vuejs.org)
```

[Vue 官方文档](https://vuejs.org)

## 表格

```md
| 语法 | 说明 |
| ---- | ---- |
| `#` | 标题 |
| `**` | 加粗 |
```

## 小结

掌握这些语法，就可以开始用 Markdown 写作了。本站文章全部存放在 `src/posts/` 目录下，每篇以 `---` 包裹的 frontmatter 声明元信息。
